# 帖子模板库

## 模板1：事件播报（短帖）
```
[一句话说清楚发生了什么]

[关键数字或细节，2-3条]

[一个判断或问题，不强行下结论]
```

**示例（链上花生风格）：**
```
Lighter上有人开了2亿ARC多单，约$2400万。
最后全部被adl平仓。

这不是第一次这种规模的定向清算了。
协议设计的问题，还是市场操控？数据在这里。
```

---

## 模板2：机会播报（seven / 副业测评君风格）
```
[项目名]：[一句话说是什么机会]

关键信息：
· 时间：
· 门槛：
· 预期收益：
· 风险点：

[我的判断/操作计划]
```

**示例：**
```
Buidlpad Phase 3：8% APY固定收益

关键信息：
· 存款窗口：2月28日-3月3日（UTC 8点）
· 上限：$20M，单地址无上限
· 结束时间：3月31日
· 链：Base

我放了X个U进去，到期更新结果。风险自判。
```

---

## 模板3：深度分析（AKL / 宏观老陈风格）
```
[标题：一个有争议或反直觉的观点]

说[X]点：

1. [核心问题/现象]
2. [原因拆解]
3. [影响/结论]

[一句收尾，可以是问题也可以是判断]
```

---

## 模板4：踩坑/复盘（七/码农出走记风格）
```
[我做了什么] + [结果]

我当时是这么想的：
[判断逻辑]

哪里出了问题：
[错误原因]

下次怎么做：
[教训]
```

---

## 模板5：科普解释（普通人小林 / 链上安全员风格）
```
弄懂了一件事：[概念名]

[用一个比喻或生活场景解释]

实际意思是：
[核心解释，1-3条]

[为什么值得了解/怎么用上]
```

---

## 模板6：观点帖（Flandre / 宏观老陈风格）
```
[反直觉或有深度的开头]

[数据或事实支撑]

[结论或引发的思考]
```

---

## ⚠️ 通用规则
- 同一条素材给多个账号用时，开头第一句必须不同
- 不同账号写同一事件，角度必须不同（见人格档案的"内容支柱"）
- 帖子里带返佣链接时，必须有真实内容包裹，不能是纯广告
- 广告合作必须标注（"合作内容" / "sponsored"）
