# 05 · 日常运营手册

> 项目跑起来后，这是每天/每周要做的事情。

---

## 每日检查（5分钟）

打开 `/dashboard`，确认：

1. **账号状态**：所有账号是否 active（绿点）？有 suspended/paused 要处理
2. **今日已发**：是否按预期在发帖？
3. **待审核**：有没有积压的帖子需要人工确认？
4. **素材库存**：各赛道素材是否充足（建议每赛道保持 20+ 条可用素材）

---

## 每周工作（30-60分钟）

### 1. 补充素材库

进入 `/materials`，手动添加本周看到的好内容：

- 加密：本周重要链上事件、宏观政策动向
- AI：新工具发布、重要论文、产品更新
- 撸毛：新的 testnet 机会、值得关注的项目

### 2. 检查各账号发帖质量

进入每个账号的详情页，抽查本周发的内容：
- 风格是否和人设一致？
- 有没有出现 AI 腔？
- 互动数据如何？

质量差的账号：去 `docs/02-personas.md` 优化对应人设，同步更新数据库。

### 3. 手动补几条"真实感"内容

每个账号每周至少手动在推特上：
- 回复 1-2 条评论
- 转发 1 条非系统生成的内容
- 或者随手发一条非常即兴的想法

这能显著降低机器人识别风险。

---

## 账号出问题时的处理流程

### 发现某账号帖子质量下降

1. 暂停该账号：把 `accounts.status` 改为 `'paused'`
2. 打开 `docs/02-personas.md` 重新审视人设档案
3. 用测试素材重新生成几条，判断质量
4. 更新 `accounts.persona_story` 字段
5. 改回 `'active'`

### 发现某条帖子有问题（发出去了）

1. 手动登录推特，删除该帖子
2. 在数据库把对应 post 的 status 改为 `'archived'`
3. 检查是哪条素材生成的，给该素材打上不良标签或删除

### 账号被限流

1. 立刻把 `accounts.status` 改为 `'suspended'`
2. 停止该账号24-48小时
3. 检查 `activity_logs` 找触发原因
4. 恢复后从低频开始（每天1条），观察1周

---

## 素材质量标准

手动添加素材时，参考以下标准：

**优先添加（importance = 4-5）**：
- 原创数据或链上发现
- 重要项目的官方公告
- 有争议的观点（适合评论型内容）
- 罕见的操作教程

**一般添加（importance = 3）**：
- 常规资讯
- 普通观点文章

**不要添加**：
- 来源不明的消息
- 可能违规的内容
- 已经过时超过3天的新闻（除非标为 evergreen）

---

## 月度复盘

每月最后一天：

1. 查看各账号互动数据（点赞/转发/回复），找出效果最好的5条帖子
2. 分析：是什么内容类型？什么角度？什么时间发的？
3. 更新 `docs/03-ai-prompts.md` 中的角度优先级
4. 调整表现差的账号的 `post_per_day` 或 `active_hours`
5. 确认下月的 API 额度是否需要升级
